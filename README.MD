# Challenges Mod

A mod that adds 2 configurable challenges to play: "Magnus run" and "Maths run".
Both of the runs impose hiring restrictions, so the mod helps to enforce it instead of manual control.

Github repo: [BB Challenge runs](https://github.com/Allenhorst/BB-Challenge-Runs)

## How to install

Just copy the .zip into your data folder(SteamLibrary\steamapps\common\Battle Brothers\data for steam installations). This mod requires [MSU](https://www.nexusmods.com/battlebrothers/mods/479).

## Magnus run

Originally, "Magnus run" is a Lone Wolf start on seed UpRjAFrHrE. Only brothers with names Magnus,Karl,Steinar,Ragnar,Geralt and name equal to the Lone Wolf name can be hired. Brothers joined on the event stays in roster too, but their names are not added to allowed list. Allowed list can be checked in Mod Settings UI screen.

## Maths run

Another run that limits the hiring. Before hiring, a brother’s price is checked to be divisible by a configurable number. Default value for division is 150, but it can be changed for simplifying the challenge.
The number for division can be changed in Mod Settings UI screen.
